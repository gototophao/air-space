Air Space / 内容更新

填好 Excel，更新网站。

选择已填写的内容表，生成网站使用的内容文件。表格在当前浏览器内处理，不会上传到服务器。

1. 填写并保存内容表

打开 下载 Excel 内容表，填写 Home、People、News 等工作表。成员、新闻和合作单位只有“发布”列填写 Yes 才会显示。

照片单独放进 assets 对应文件夹。请保留原表的工作表名称和第 5 行表头。

2. 选择填写好的 Excel

还没有选择文件。

3. 下载并替换

将下载的文件改名为 content.js，覆盖网站文件夹中的同名文件，然后重新打开或刷新 网站首页。浏览器可能自动命名为 content (1).js，请先改回原名。

如果已经启用 README 中的 GitHub 自动发布方式，只需把 Excel 上传到仓库的 data 文件夹并覆盖原文件，再上传相应照片，GitHub 会生成内容并重新发布网站。
